# Hệ thống Một cửa dịch vụ hỏi đáp

## Giới thiệu

Đây là dự án xây dựng hệ thống một cửa dịch vụ hỏi đáp, hỗ trợ sinh viên gửi yêu cầu và theo dõi phản hồi từ cán bộ.

## Công nghệ sử dụng

- ASP.NET Core
- Entity Framework Core
- SQL Server
- HTML
- CSS
- JavaScript
